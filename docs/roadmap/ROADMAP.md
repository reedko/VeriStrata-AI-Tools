# Collaboration roadmap

## Available now

- Public 23-operation Partner contract, SDK, Swagger, MCP and Lab.
- Deterministic exact/near duplication and domain-concentration preflight.
- Evidence-backed topic/job creation with explicit limitations.

## Proposed canonical-platform extensions

1. Source-aware preparation that consumes registered URL/text sources through the existing ingestion and claim-framing pipeline.
2. Document-level provenance receipts: retrieval time, canonical URL, content hash, transformation history and extraction version.
3. Cross-source occurrence and transmission observations with time uncertainty—never automatic actor attribution.
4. Evaluation fixtures for prompt injection, citation laundering, false corroboration, temporal leakage and retrieval poisoning.
5. Release-grade assessment bundles usable by training, RAG and model-evaluation systems.

These are collaboration seams, not duplicated implementations. Changes to the private platform should preserve its canonical evidence and review architecture.
